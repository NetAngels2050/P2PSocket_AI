# P2P 用户使用手册

> 适用版本：1.0.0　依据：NFR-61、设计 08 §8、06 §2/§3　随版交付（M4-08）
> 读者：**客户端使用者**（在自有设备上建立内网穿透映射）与**服务端管理员**（运维公网/内网服务端）。安装部署见 [部署手册](../deploy/)（服务端/Windows/Linux 三篇）；故障排查见[排障指南](troubleshooting.md)（M4-09）。

## 0. 产品与访问入口

### 0.1 产品模型一图流

```
[本机设备] ──映射(本地端口)──▶ [目标设备] ──▶ 目标地址(self 或 内网 IP:端口)
     │                              │
     └──────── 控制面：服务端 ───────┘
   数据面：打洞成功→设备间直连(direct)；不可穿透→经服务端中继(relay)
```

- **远程码**：每台设备的 6 位标识（如 `712152`）。映射用「目标远程码」定位对端设备——类似给设备起的一个短号。
- **虚拟 IP**：注册成功后本机出现虚拟网卡，固定 `100.64.0.2`。**映射监听绑在虚拟 IP 上**（不是 127.0.0.1）——本机访问映射地址须用 `100.64.0.2:端口`，127.0.0.1 上的同端口服务互不干扰。
- **可见性**：两台设备互相可见的前提 = **登录同一账号** 或 **处于同一分组**。互相不可见时一切按远程码的访问都会被拒（4003）。
- **中继回退**：打洞失败（NAT 组合不可穿透）时，若目标设备开启了「中继回退」，流量经服务端转发（relay 态）——服务仍可用，速率受服务端带宽与限速约束。

### 0.2 访问入口

| 端 | 地址 | 说明 |
|---|---|---|
| 客户端本地管理页 | `http://127.0.0.1:7100` | 仅本机回环可达（Linux/远程机用 SSH 隧道 `-L 7100:127.0.0.1:7100`） |
| 服务端管理后台 | `http://<服务端>:7500` | 默认仅绑定 127.0.0.1（不对公网暴露）——经 SSH 隧道 `-L 7500:127.0.0.1:7500`，或经一条映射到服务端机客户端的 `self:7500` 映射访问 |

## 1. 首启向导（`/wizard`）

安装完成后浏览器打开 `http://127.0.0.1:7100`，未注册设备自动进入向导（已注册设备访问 /wizard 会直接跳回主界面）。三步：

### 第 1 步 · 服务端

1. 填**服务端地址**，格式 `host:port`（如 `203.0.113.10:7000`，端口默认 7000）；
2. 点 **「测试连接」**——显示「连接成功」后「下一步」才可用（未通过测试无法进入下一步；失败原因会显示在按钮旁）。

### 第 2 步 · 分组方式

三种方式选其一（决定这台设备与谁互通）：

| 方式 | 说明 | 附加输入 |
|---|---|---|
| **默认分组** | 加入服务端默认分组，与同分组设备互通 | — |
| **邀请码入组** | 输入 6 位分组邀请码（数字 2-9 + 小写字母去混淆字符集，不含 0/1/o/i/l），入组后与组内设备互通 | 邀请码（6 位） |
| **账号注册建组** | 新建账号并创建专属分组（「我的分组」）；其它设备用同一账号登录即可互见 | 用户名（≥3 字符）+ 密码（≥6 字符） |

再加一个**设备名**（默认「我的设备」，用于设备列表展示）→ 点 **「注册」**。

### 第 3 步 · 完成

注册成功页展示本机三要素，**请妥善保管**：

- **远程码**（6 位，等宽字体展示，可复制）——其它设备建映射时用它定位本机；
- **虚拟 IP**（100.64.0.2）；
- **分组**（已加入的分组名）。

点 **「进入控制台」** 回到主界面（此时系统 phase 变为 running，向导不再出现）。

> 已有账号的场景：两台设备都选「账号注册建组」但用**同一用户名密码**？不行——账号注册是**新建**账号；第二台设备应在向导选「默认分组」或「邀请码入组」注册后，再到「账号」页用既有账号登录（§3），即实现同账号互见。

## 2. 仪表盘（客户端 `/`）

登录后首屏，四块内容：

1. **设备信息卡**：远程码 / 虚拟 IP / 控制通道（连接状态）/ 登录态；
2. **速率图**：本机所有映射的上行/下行/中继速率实时曲线（纯 SVG，10s 刷新）；
3. **映射速览表**：名称 / 本地监听 / 目标远程码 / 路径（direct=直达 / relay=中继）/ 实时速率；
4. **流量汇总卡（本次运行累计）**：按设备维聚合的上/下行/中继字节与总计——**本机视角、进程重启后清零**（服务端另有全生命周期累计）。右上「导出 CSV」= 两段式表格（映射明细+设备汇总）新窗口直下，Excel 可直接打开（UTF-8 BOM）。

### 重置远程码

信息卡上「重置远程码」按钮（哑节点亦可操作）：

- 确认弹窗会提示：**重置后旧远程码立即失效**——引用旧码的映射与打洞请求将被拒绝（4003），对端会收到失效提示并需改用新码；
- 确认后新码以弹窗一次性展示（不再显示第二次，请当场记录）；
- 典型用途：怀疑远程码泄露、或整理设备命名体系。

## 3. 登录与账号（客户端 `/login`）

### 3.1 登录（绑定账号）

表单输入**用户名 + 密码** → 登录。登录后本机与「同账号设备」互相可见（可见性=同账号 ∪ 同分组）。顶栏显示 `用户名（已登录）`。

### 3.2 登出与哑节点

登出确认文案已说明后果：**登出后本机转为哑节点——仅响应既有隧道，不能主动发起映射**（不重启、不注销设备）。哑节点状态下主动操作类页面（映射启停、分组管理等）按钮置灰；设备/分组/映射三页顶部显示「哑节点」横幅。恢复：在账号页重新登录——登录会自动重置连接能力（无需重启客户端或等待重连，2026-10-11 起）。

**登录态保持（记住我）**：登录成功后凭据在本机加密保存（Windows DPAPI；Linux 由文件权限保护），**客户端/电脑重启后自动登录**——无需再次输入账号密码，web 打开即为已登录态，端口映射同步自动恢复。**网络断开重连后同样自动恢复**（2026-10-18 起）：断线期间登录绑定随服务器会话丢失，重连成功即自动重放登录（服务端亦自动继承登录态，双保险），登录态与可见性无感保持；断线窗口内判「失败」的映射也会自动补试一轮。**登出即忘记**：登出会清除记住的凭据，重启后回到未登录状态（下次须手动登录一次）。修改密码后同样须用新密码重新登录一次。

### 3.3 修改密码

已登录态点「修改密码」弹窗：当前密码 / 新密码（≥6 位）/ 确认新密码 → 成功后**自动登出**，请用新密码重新登录。改密只影响账号口令，设备注册与映射不受影响。

## 4. 端口映射（客户端 `/mappings`）——核心操作

### 4.1 概念

一条映射 = 「本机虚拟 IP 上的一个端口」→「目标设备上可达的一个地址」。本机应用连接 `100.64.0.2:<本地端口>`，流量经隧道直达目标设备上的 `<目标地址>:<目标端口>`。

### 4.2 新建映射

列表页「新建映射」打开抽屉表单：

| 字段 | 说明 |
|---|---|
| 名称 | 自定义，用于展示 |
| 协议 | **TCP** 或 **UDP**（UDP 适合 DNS/游戏等场景；单条映射单协议，需要两种就建两条） |
| 本地端口 | 本机监听端口（1~65535，绑虚拟 IP 100.64.0.2） |
| 目标远程码 | 对端设备 6 位远程码（可从设备页「带入远程码新建映射」自动填入） |
| 目标模式 | **self**=目标设备本机（即目标设备自身回环地址，最常用——例如访问目标机上跑的 Web 服务）；**IP**=目标设备所在内网的其它主机（如 `192.168.1.50`，须在对端「网段」白名单内，见 §5.3） |
| 目标地址 / 目标端口 | IP 模式必填目标地址（IPv4/IPv6 均可）；目标端口两种模式都填 |

创建成功提示「**已创建（默认停用，启用后开始打洞）**」——新建映射默认停用，手动「启用」才开始打洞/转发，避免误动作。

### 4.3 启停 / 重试 / 删除与状态语义

操作列按钮随状态变化（哑节点下全部置灰）：

| 按钮 | 语义 |
|---|---|
| 启用 / 停用 | 启用=开始打洞并转发；停用=拆监听停止转发（配置保留） |
| 重试 | **仅 failed 态提供**——打洞失败后重新尝试 |
| 删除 | 二次确认后连配置一起删除 |

状态标签（列表「状态」列）：

| 状态 | 含义 |
|---|---|
| 打洞中（punching） | 正在尝试直连 |
| **直达（direct）** | 打洞成功，设备间直连（最优路径） |
| **中继（relay）** | 打洞不可穿透，经服务端中继转发（需对端开启中继回退，§5.1） |
| 失败（failed） | 打洞失败且无回退资格——点「重试」，或检查对端中继回退开关 |
| **失效（invalid）** | 授权变更被服务端下线（对端网段移除/远程码重置/设备或用户禁用/退出共同分组）——置灰不可用，编辑修正后重新启用 |
| 已禁用（disabled） | 本地停用态 |

编辑约束：**停用态才可改本地端口/协议**（与与服务端配置规则同口径）；名称/目标任意状态可改。

### 4.4 白名单网段提示（IP 模式）

目标模式选 IP 时，表单下方实时列出**对端设备配置的开放网段**，并提示「段外地址将被拒绝（4002）」。填写的目标地址若不在对端网段内，创建时服务端会以 4002 拒绝——请先联系对端在「网段」页添加（§5.3）。

### 4.5 访问映射

本机应用连接 **`100.64.0.2:<本地端口>`**（注意不是 127.0.0.1——虚拟 IP 上的监听与回环同端口服务是两个独立监听位，排障时勿混淆）。

## 5. 设备与分组

### 5.1 设备发现（客户端 `/devices`）

展示**与本机互相可见**的设备（同账号 ∪ 同分组）：设备名 / 远程码 / 虚拟 IP / 分组 / 开放网段 / 在线状态，顶部可按分组筛选。两列重点操作：

- **中继回退开关**（每设备一行）：开启后，到该设备的打洞失败时自动经服务端中继兜底（映射转 relay 态）；关闭则打洞失败即 failed。**目标设备在云服务器/受限 NAT 后时建议保持开启**（打洞大概率不可穿透，中继是常态承载）。
- **操作 → 新建映射**：带入该设备远程码直接跳转映射新建表单（§4.2）。

页面顶部哑节点横幅同 §3.2。设备列表为事件驱动刷新（对端上下线自动更新，无需手动刷新）。

### 5.2 分组（客户端 `/groups`）

**已加入分组表**：分组名 / 准入策略 / 成员数 / 我的角色 / 操作。

- 我的角色=**所有者**：可「邀请码」「成员管理」「编辑」「解散」；
- 我的角色=**成员**：仅「退组」。

**凭码入组**（页头按钮）：输入 6 位邀请码加入目标分组；若该分组策略为「需审批」，提交后显示「等待所有者」提示（非错误），获批后入组。

**新建分组**：分组名 + 准入策略（自由加入 free / 需审批 approval）。创建者即所有者。

**邀请码**（所有者）：打开弹窗即生成当前分组唯一邀请码（覆盖式——重新生成则旧码失效）；可撤销（撤销后空态）。邀请码用于「凭码入组」与向导「邀请码入组」。

**成员管理**（所有者）：列出组内可见设备（同组过滤、排除本机），可将成员移出（二次确认，其跨分组可见性即时回收）。

**审批**（所有者）：您创建的分组，「成员数」列显示如 `2（待审：3）`——括号内为该组待处理申请数（无待审时显示 `2（待审：0）`）；操作栏点「审批」打开弹窗，列出该组待审批申请（申请设备/申请时间），每页 10 条，勾选一条或多条后「同意」或「拒绝」（批量处理、逐条生效），翻页后勾选不保留；该组全部处理完弹窗自动关闭。批准后申请设备立即入组、双方设备列表即时刷新。非创建者的分组不显示待审数与「审批」按钮。

**退组 / 解散**：均二次确认；解散会回收组内全部成员的跨分组可见性，不可恢复。

### 5.3 网段（客户端 `/segments`）——开放网段白名单

定义「**允许别台设备经本机访问的内网地址范围**」（L3 授权）。表单支持 CIDR（如 `192.168.1.0/24`）或**单地址**（如 `10.0.0.5`，按 `10.0.0.5/32` 处理）；页面标注即时生效语义：

- 添加/移除**即时生效**：引用本网段的既有映射若段外将立即失效（对端收到 invalid 提示）；
- 全开放须**显式**填 `0.0.0.0/0`（留空=什么都不放行，fail closed）；
- `self` 目标不受网段限制（恒放行），网段只约束 IP 模式映射。

## 6. 网络诊断与运维（客户端）

### 6.1 NAT 判型（`/settings` → 网络诊断（NAT 判型））

点「开始探测」执行 RFC5780 子集判型（**受限型 NAT 须等超时判据，全程可数十秒，请耐心等待**）。结果六维：

| 维度 | 读法 |
|---|---|
| UDP 映射类型 | **端口无关映射**（好，映射端点稳定）／**地址端口相关映射**（symmetric，UDP 预测打洞基本无望） |
| UDP 入站过滤 | **端点无关过滤**（好，任意对端可回）／地址端口相关过滤 |
| 公网映射端点 | 探测学到的本机公网端点 |
| TCP 端口分配 | **同时打开**／**顺序分配**（TCP 打洞 N≥2 可用性依据）／随机 |
| TCP 端口依赖 | 地址无关／地址端口相关 |

判型对直连可能性的粗读：双方均「端口无关映射 + 端点无关过滤」→ UDP 直连概率高；任一方 symmetric → UDP 直连难，期待 TCP 打洞或中继。若提示「服务端未配置第二地址（stun_alt_addr）：UDP 映射/过滤两维不可判（单公网 IP 降级）」——属服务端配置限制，请联系管理员（或参照部署手册配置 `stun_alt_addr`）。

### 6.2 设备连通性（隧道 PING）

输入**目标设备远程码** → 探测（须先启用一条到该设备的映射以建立隧道；无活隧道时明确报错并提示）。结果：发送/接收（丢包直观可见）、最小/平均/最大 RTT、承载路径（direct/relay）。用于快速验证「到某台设备的隧道通不通、走哪条路」。

### 6.3 服务端连通性

对设置里**全部候选服务端地址逐个** TCP 探测（30s 预算），结果表逐行显示可达性——服务端迁移/多线路场景下确认哪条线路可用。

### 6.4 打洞队列与隧道 REKEY

- **打洞队列**：当前队列深度 + 正在打洞的目标（空闲时显示「（空闲）」）——排查「点了启用怎么没动静」。
- **隧道与 REKEY**：活隧道列表（对端/本端角色/承载）；每行「触发 REKEY」按钮手动轮换会话密钥（正常由定时自动轮换，手动用于安全演练/验证隧道活性）。结果文案：成功（ok）／非发起方（not_initiator——本端为响应方，须在对端触发）／忙（busy——上一次还在进行）／失败（failed，附明细）。

### 6.5 日志（`/logs`）

客户端运行日志 newest-first 浏览：**级别过滤**（debug/info/warning/error/fatal 精确类别）+ 分页（每页 200 条）+ 「导出」（按当前级别过滤、时间正序、纯文本附件新窗口直下）。日常排障先看 warning/error。

### 6.6 升级页与版本不符引导（`/upgrade`）

- **自动进入**：客户端协议版本与服务端不兼容时，控制通道被拒，浏览器自动打开 `/upgrade?reason=version` 并顶部警示「协议版本不兼容」——按「下载地址」取新版本，覆盖安装后重连即可（升级不丢数据：配置/凭据/映射在数据目录，见部署手册）。
- **手动查看**：菜单「升级」直达。展示最新版本 / 协议兼容范围 / 下载地址（el-link）/ 更新说明；服务端未配置或不可达时显示「暂无法获取升级信息」。

### 6.7 设置页其余项（`/settings`）

- **设备名**（注册后可修改）：未改名前显示主机名（注册时的默认名）；输入新名（1~64 字符）→ 点「改名」即时生效——同步更新服务端记录，同账号/同分组其他设备的设备列表自动刷新；本机重启后名字保持（改名已持久化，凭据恢复重注册亦沿用，不会退回主机名默认值）；
- **服务端地址候选**：多候选列表（可上移/下移调优先级）——主地址失联自动切换下一候选；
- **本地 Web 端口**：改后**重启客户端生效**（页面有提示当前仍由旧端口服务）；
- **高级参数（只读）**：打洞并发路数/隧道保活/重连退避等（当前版本只读展示）；
- **关于**：版本号 / 构建提交（git 短哈希）/ 协议版本——报障时请一并提供。

> 顶栏若出现持续告警条「**虚拟网段冲突**：本机网络与虚拟网段重叠，映射通信可能异常」——本机物理网络占用了 100.64.0.0/24 网段，须调整本机网络或联系管理员调整虚拟网段（服务端 `virtual_subnet` 键）。

## 7. 服务端管理后台（server-app）

浏览器访问 `http://<服务端>:7500`（接入方式见 §0.2）。

### 7.1 登录（`/login`）

- 首次部署账号 **admin / admin**——登录即弹「正在使用默认口令（admin/admin），请立即修改管理员密码」强制改密（当前密码/新密码/确认新密码 → 「保存并继续」）。**务必修改**：默认口令是最大安全隐患。
- 忘记密码：服务器上执行 `p2p-server --reset-admin` 重置回 admin/admin（见服务端部署手册）。
- 会话 8 小时有效，过期自动回登录页；同 IP 连续失败有限速（渐进延迟）。

### 7.2 仪表盘（`/dashboard`）

六组指标卡 + 打洞成功率 24 小时曲线：**在线设备数**（连接级真相源）/ 分组数 / 映射状态分布（直达/中继/失败/失效/未知）/ **中继**（自启动累计转发字节与活跃会话）/ STUN 请求放行与丢弃 / 打洞成功率（punch_stats 24h）。右下角版本角标（版本号+构建提交——与服务端后台对版本时看这里）。

### 7.3 用户（`/users`）

用户列表（用户名/角色/状态/设备数/创建时间）+ 两项操作：

- **禁用 / 启用**：禁用=该用户名下**在线设备立即降级哑节点**（收到 user_disabled 提示，主动操作全禁），心跳保持；启用后设备**重连即自动恢复**——重连时服务端继承登录态（用户已启用即继承生效）+客户端凭据自动重放，无需手动重新登录（2026-10-18 起；此前须重连并重新登录）。
- **重置密码**：生成 10 位**临时密码一次性弹窗展示**（「我已保存」后不再显示）——用户拿到临时密码登录后自行改密。

页头**注册开关**（开/关）：关闭后新设备「账号注册建组」被拒绝（默认分组/邀请码入组不受影响）——公开服务端防滥用的第一道闸。

> 内置 admin 不可禁用/重置（页面按钮置灰）——管理员失联走服务器 `--reset-admin`。

### 7.4 设备（`/devices`）

全量设备表：设备名/远程码/虚拟 IP/归属用户/系统/分组/在线（连接级，与禁用态正交）/状态（正常/已禁用）/创建时间。操作：

- **禁用 / 启用**：禁用=设备**立即断线**（登录/注册/信令全拒；引用它的映射在对端失效提示）；同 MAC 重注册也被拒。启用后设备重连即恢复。
- **解绑**（二次确认）：删除设备全部记录（分组/映射/统计一并清理）；**同 MAC 重新注册=全新身份**（新 deviceId/新远程码）。用于设备报废/换装。
- **重置远程码**：等价客户端侧重置（§2），新码弹窗一次性展示——管理员代操作场景。

### 7.5 分组（`/groups`）

总览表（默认分组置顶）：分组/所有者/成员数/待审批数/准入策略/创建时间。两块操作：

- **默认分组准入策略**（页头单选：自由加入 free / 需审批 approval）：双写生效——既改存量默认分组，也是后续新建分组缺省口径。
- **待审批队列**：跨全分组的 pending 申请（默认分组+approval 策略或各 approval 分组），逐条批准/拒绝——批准即入组、双方设备列表即时刷新。

### 7.6 映射（`/mappings`）

**只读**视图（映射的启停/编辑在客户端做，服务端不代操作）：名称/归属设备/目标（远程码或 IP:端口）/本地端口/启用/状态/上下行与中继流量/统计更新时间。支持**按归属设备**与**按状态**双筛选，顶部有状态计数聚合。流量列=客户端 30s 周期上报的全生命周期累计（与客户端本地「本次运行累计」口径不同，两视角互补）。

### 7.7 中继（`/relay`）

- **中继服务开关**：关闭确认文案已说明语义——**新的中继分配将被拒绝（5002），存量会话不受影响继续转发**（排水式关闭，不断业务）；重新开启即恢复放行。
- **限速（B/s）**：0=不限。全局令牌桶——**即时生效**；限速时存量中继降速等待、不打断，**新的**中继分配请求才会被拒。
- **会话表**：当前活跃中继会话（会话 ID/A 端与 B 端（控制 IP·承载）/转发字节/最近活跃/创建时间），10s 自动刷新——排查「为什么走中继、中继转了多少」看这里。

### 7.8 系统（`/system`）

- **配置项表**：19 个服务端运行键（分组可见行级编辑，bool 即存、枚举下拉、数值/文本改后「保存」点亮）。标注「**重启生效**」的 7 键（public_addr/stun_auth/stun_alt_addr/stun_rate_per_ip/stun_rate_per_device/stun_circuit_pps/log_level——服务构造期/日志装配期一次性读取）改后须重启服务端进程；其余键（registration_open/max_devices/default_join_policy/update_*/保留天数等）运行期现读即时生效，`relay_rate_limit` 与中继页限速同源。非法值（超范围/格式错）服务端整单拒绝并显示原因。
  - 常用键速查：`registration_open` 注册开关（与用户页同源）、`default_join_policy` 默认分组策略、`public_addr` **云服务器必配**（NAT 部署下中继端点通告，见部署手册）、`update_*` 四键升级引导页内容源。
- **审计日志**：安全相关操作流水（newest-first）：时间/事件/详情，支持按事件类型过滤（如 `group_join`）+ 分页。审计不含密码/密钥/邀请码明文。

## 8. 常见状态与错误码速查

| 码/状态 | 场景 | 一句话处置（详见排障指南） |
|---|---|---|
| 4002 | 建/改映射、IP 目标段外 | 对端「网段」页加白名单，或改目标为段内地址 |
| 4003 | 远程码无法解析 | 对端重置过码 / 双方无可见性（同账号或同分组）/ 对端离线 |
| 5002 | 打洞回退被拒 | 中继服务关闭或限速耗尽——服务端中继页检查 |
| 5004 | 协议版本不符 | 升级客户端（自动开 /upgrade 引导页） |
| 2002 | 主动操作被拒 | 本机为哑节点——重新登录 |
| 映射 failed | 打洞失败 | 对端开中继回退重试；双方 NAT 判型（§6.1）评估直连可能 |
| 映射 invalid | 授权变更失效 | 检查对端网段/远程码/禁用状态，修正后重新启用 |
