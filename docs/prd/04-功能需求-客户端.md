## 4.3 端口映射引擎

| 编号 | 需求 | 优先级 | 补充说明 |
|---|---|---|---|
| FR-C-301 | 映射监听：按映射规则在本机**虚拟 IP** 的本地端口监听（不占用/不冲突本机 127.0.0.1 与物理网卡端口） | P0 | 决策 D2 核心语义 |
| FR-C-302 | 流量转发：到达监听端口的流量经 P2P 隧道送达目标设备，由目标设备连接其本机或已开放内网 IP 的目标端口 | P0 | 目标范围约束见决策 D15 |
| FR-C-303 | 支持协议：TCP（P0）与 UDP（P1）映射，每条映射单选一种协议 | P0 | 决议 OQ-6 |
| FR-C-304 | 映射配置字段：名称/备注、本地端口、目标远程码、目标地址（默认对端本机）、目标端口、协议、启用/禁用（中继回退开关自 v0.4 起为**目标设备级配置**，见 FR-C-803） | P0 | 字段表详见 [06 §2](06-网络与打洞.md)；OQ-10 |
| FR-C-305 | 映射 CRUD 与启停在本地 Web 操作；创建时服务端校验授权，配置同步至服务端存储 | P0 | FR-S-801 |
| FR-C-306 | 映射状态实时展示：空闲 / 打洞中 / 直连已建立 / 中继 / 失败（含原因） | P0 | 状态机见 [06 §5](06-网络与打洞.md) |
| FR-C-307 | 目标侧开放控制：本地 Web 可声明"允许访问我的内网 IP 段"（CIDR 列表，默认空=仅本机） | P1 | 决策 D15；白名单同步至服务端（FR-S-802） |

## 4.4 打洞执行

| 编号 | 需求 | 优先级 | 补充说明 |
|---|---|---|---|
| FR-C-401 | UDP 打洞：经服务端内置 STUN(UDP) 获取公网端点，按信令协调与目标同时互发包 | P0 | 时序见 [02 §3.4](02-总体架构.md) |
| FR-C-402 | TCP 打洞（端口预测法）：经 STUN(TCP) 获取公网端口后，按**打洞并发路数 N**（可配置，默认 3、范围 1~5）同时发起 N 条 TCP 连接，目标端口 = STUN 公网端口 **+(N−1)**（N=1→+0、N=2→+1、N=3→+2、N=4→+3、N=5→+4，最大偏移 +4） | P1 | 决策 D10（OQ-1 决议参数化） |
| FR-C-403 | 作为哑节点时：不发起打洞申请，但须响应服务端转发的打洞信令并配合完成打洞 | P0 | 原始需求第 8 条 |
| FR-C-404 | 打洞结果上报服务端（用于统计与中继决策） | P1 | |
