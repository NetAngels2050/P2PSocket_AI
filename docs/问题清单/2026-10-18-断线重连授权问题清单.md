## 1. 根因链（R1 主体，用户报障的代码证据）

1. 控制通道断线自动重连正常（退避 1s→30s，FR-C-604）——设备重新在线；但服务端**每条 TCP 连接 = 新 `ControlSession`**，登录绑定 `OwnerUserId` 从 null 开始（ControlSession.cs:99），旧连接上的登录态随断线丢失。
2. 批次 1 修复 D（P2 方案 a"记住我"）的凭据自动重放**只挂在冷启动路径** `RunRegisteredPathAsync`（幂等闸一次性）；`ClientRuntime` 未订阅 `ControlClient.StateChanged`/任何会话重建事件——运行中重连后没有任何代码路径重发 0x21。
3. UI 掩盖真实状态：`ctx.LoginUser` 只在登录/登出时改（AuthApi.cs:39/53），重连不清除；客户端 Capability 重连后重置 Normal（ControlClient.cs:399）→ `/api/auth/me` 继续返回 `{username, mode:"normal"}`——**客户端显示已登录、服务端实际未登录**。
4. 可见性降级（GroupService.VisibleDevices：本账号设备要求会话级 `OwnerUserId` 非空 ∪ 共同分组）：同分组设备仍可见（已有映射靠 60s 回切自愈）；**本账号无共同分组设备互不可见**——0x40 找不到（映射启用 4003"目标远程码不存在或不可见"）、打洞 L2 拒绝、映射增改 4001。与批次 1 P3 同源机制，但触发点从"重启后未登录"变为"运行中断线重连后未登录"，且连 LoginSucceeded 事件都没有——补恢复链路也不会触发。

## 2. 修复内容

### 2.1 修 A：会话重建沿凭据重放（客户端）

- `ControlClient` 新增 `SessionReestablished` 事件：`_sessionGen > 1` 的 Established（断线退避重连/强制重连）触发；首连与 NeedRegister→注册完成的同连接迁移不触发。
- `ClientRuntime.OnSessionReestablishedAsync`：①有记住的凭据 → `LoginBindAsync` 重放（`LoginSucceeded` 统一驱动 LoginUser 口径+映射补恢复，与冷启动同款）；Ack.Ok=false → 清凭据+清 UI 登录态；发送异常 → 保留凭据下次重连再试；②无凭据而 UI 残留登录态 → 如实清除并广播 `login_state`（TD-16：事件仅提示，前端 refetch /api/auth/me）。
- 竞态消解：登出即忘记（批次 1 P2 方案 a）使登出后的重连沿无凭据可重放，不与用户手动登录竞争；登录在途的双 0x21 经请求门串行且幂等。

### 2.2 修 B：心跳判死阈值默认 75s（服务端）

- `ServerOptions.HeartbeatSection.TimeoutSec` 默认 30→75；appsettings.json 同步；Validate 建议文案同步"（默认 75）"。08 §5.1 配置示例同步。
- **存量部署注意**：服务器侧 appsettings.json 若显式写了 `"timeoutSec": 30`，升级覆盖或手动改值任选其一（删掉该键用代码默认亦可）。

### 2.3 修 C：failed 映射会话重建沿兜底（客户端）

- `ClientRuntime.RetryFailedMappingsAsync("reconnect")`：会话重建沿对 failed 态映射逐条 `MappingEngine.RetryAsync`（幂等：failed 有监听重入打洞队列、无监听先拆后建全量重启用、非 failed no-op）；置于登录重放之后（同分组可见性不依赖登录，重放失败亦重试）；条数>0 记日志（可观测性锚点）。

### 2.4 修 D：重连登录态继承（服务端，02 §2.5"重连会话语义"）

- `ControlSession.HandleProofAsync` 在 `DeviceRegistry.Register` 踢旧线前：读同设备旧会话 `OwnerUserId`，查库确认用户存在且未禁用后**继承到新会话**。
- 语义边界（不走库恢复的理由）：`Device.OwnerUserId` 登出保留在库（0x22"下次登录免重绑"），从库恢复会把登出洗白成已登录；**内存继承**才正确——登录中旧会话（uid）→继承恢复可见性/分组管理（R1 服务端侧兜底，与修 A 双保险）；登出旧会话（null）→继承 null 保持登出语义（R4 可见性主体）；Capability 不继承（新会话初始 normal 与客户端镜像一致，避免被动会话语义跨连接引入 2002 回归）；服务器重启内存全丢=合理（全部连接重建，修 A 兜底）。
