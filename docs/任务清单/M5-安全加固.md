# M5 · 安全加固 · 任务清单

> 所属文档集：[README](README.md)　创建：2026-10-21　状态：🔨 进行中（2026-10-22 起；M5-01 ✅，M5-02 ✅，M5-03 ✅，M5-04 ✅，M5-05 ✅，5/16）
> **目标**：安全评估回流三项 P0 修复＋监测响应闭环（告警/安全中心/IP 黑名单）＋平台加固（PRD 09 §1 M5 行）。
> **出口标准**：**验收场景 A-13~A-18 通过**＋收口安全复评销项（M5-16）。
> **立项背景**（2026-10-21 全量安全评估，认证/网络暴露面/注入越权/文档四专项交叉验证）：
> ①**P0 三项**——控制信道登录族（0x20/0x21/0x23）密码字段明文传输（设计 R1 仅知情接受"端点信息类"，密码材料不在其中）；开放设备注册硬编码 `Approved=true` 直入默认分组（任何人指向公网服务器注册设备即获组内互访；设计文档 07 §5 声称的 max_devices 与单 IP 注册频控**未实施**——文档-代码漂移）；0x21 登录零防爆破（公网 7000 可任意速率撞库）。
> ②**检测响应层缺失**——审计事件 30+ 类、管理端处置动作齐备（禁用/解绑/踢线/重置码/中继开关），但无任何告警通道与准入闸门，「预警后人工介入」目标缺中间层。
> ③**平台加固欠账**——服务端 root 运行零沙箱、客户端本地 Web 无鉴权（LocalSystem 代理面）、deviceSecret 明文落库、升级产物无签名且 update_url 允许 http。
> **决议**：OQ-20 四项——范围三阶段全量 / 密码修复=登录字段 ECIES 化（D21 维持）/ 注册开关默认开放 / TOTP 留待办池；**开工口径 OQ-21 三项**（2026-10-22 用户确认）——ECIES 混布**硬切**（服务端不设明文过渡双轨、旧客户端明文登录一律失败，先客户端后服务端单一维护窗口）/ 产物签名**降级哈希核验**（无证书不购入）/ 告警 webhook **通用 JSON 暂不接厂商**（结构预留扩展位）；走查回流 **OQ-22** 三注记（SEC-73 命中审计口径/SEC-83 缺钥降级与不可解行处置/SEC-71 四入口——PRD v0.15）。
> 任务执行受 [开发规范](../开发规范/README.md) 约束；状态图例与使用规则见清单 README。
