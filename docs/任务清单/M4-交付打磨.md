> **已于 M1~M3 交付（本清单出口核对，不重复建设）**：NFR-31 单文件自包含发布（M1，portable 包 M3-18 已实际分发多机）；NFR-35 端口/网段/路径全配置化+错误明确诊断（M1 配置体系+M3-15 ParseAltEndpoint 启动校验等）；NFR-36 本地 SQLite 持久化+EF 自动迁移（M1，M3-18 存量库跨两版升级实证）；NFR-12 性能可观测（每映射速率/累计/路径=M1-32+M2-22，服务端仪表盘=M3-06）；NFR-51 结构化日志分级滚动+Web 查看导出（M1+M2-29 /logs）；NFR-52 诊断工具（服务端连通性/STUN/NAT 初判=M3-14/15/16）；NFR-53 崩溃自动重启+状态恢复（服务 Restart=always+M2-24 网卡监听自愈）；NFR-54 服务端审计日志（M2-08/12 落库+M3-08 查询 API）。
> **版本号定案**：本里程碑起统一版本 **1.0.0**（M4=首个完整交付版本；08 §1 版本注入的 Version 值，后续手动递进）。
> **编制定案（回流设计，TD-24）**：基准环境分级口径——09 §3.1"同机房两台 VPS"环境在当前项目资源下不可得（实际环境=一台公网 VPS+家宽 Windows）；落地为两级：**L1 本地自动化基准**（NatSimulator 打洞成功率矩阵/建立耗时分布/本机回环吞吐与延迟对照/资源采样——可重复运行，随 M4 交付）+ **L2 实机基准**（公网真实打洞统计脱敏取数进报告；两台 VPS iperf3 吞吐=环境依赖预留位，待用户环境）。报告对 L1 数据如实标注"本机回环基线≠真实网络性能"。
> 任务执行受 [开发规范](../开发规范/README.md) 约束；状态图例与使用规则见清单 README。
